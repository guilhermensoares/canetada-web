# Canetada

Repositório oficial da versão web pública do **Canetada**.

## Objetivo

Este repositório é a base de publicação do jogo. O histórico de protótipos e desenvolvimento permanece separado.

## Regras da versão pública

- todos os sprites e assets do jogo devem ser locais;
- nenhum personagem jogável pode depender de URLs externas para seu retrato;
- o jogo deve funcionar em desktop e mobile;
- o progresso deve ser salvo no navegador;
- o compartilhamento de progresso/mandato deve usar o domínio atual;
- o deploy será automatizado a partir da branch `main`.

## Publicação

Destino recomendado: **Cloudflare Pages** com domínio próprio.

A configuração definitiva de build será adicionada junto com a versão consolidada do jogo.
